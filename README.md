# Valmont Industries

Valmont Industries is a global leader in producing fabricated metal products, designing and manufacturing engineered support structures for infrastructure, mechanized irrigation equipment, and coatings services. Valmont's Valley brand is the world's leading manufacturer of center pivot and linear irrigation systems, with digital platforms including AgSense 365 and BaseStation3 providing remote monitoring and control of irrigation pivots.

**Website:** [https://www.valmont.com](https://www.valmont.com)
**Valley Irrigation:** [https://www.valleyirrigation.com](https://www.valleyirrigation.com)
**API Portal:** [https://apivalley.valmont.com](https://apivalley.valmont.com)

## Business Segments

- **Agriculture**: Valley center pivot and linear irrigation systems, AgSense 365 digital platform, BaseStation3 telemetry, precision ag tools
- **Infrastructure**: Steel utility poles (electrical transmission/distribution), lighting structures, traffic signal structures
- **Coatings**: Hot-dip galvanizing, powder coating, anodizing services

## Digital Platforms

### AgSense 365
Valley's unified remote management platform for center pivot irrigation. Enables remote monitoring and control of pivot status, position, speed, water application, and flow rates.

- [https://www.valleyirrigation.com/precision-ag/agsense-365](https://www.valleyirrigation.com/precision-ag/agsense-365)

### BaseStation3
On-pivot telemetry device that integrates into Valley control panels for real-time monitoring and two-way communication.

- [https://www.valleyirrigation.com/equipment/remote-devices](https://www.valleyirrigation.com/equipment/remote-devices)

### Valley API Portal
[https://apivalley.valmont.com](https://apivalley.valmont.com) - A Valley Irrigation application platform (access-controlled, no public API documentation available).

## Note on APIs

Valmont Industries does not publish a public developer API. The Valley API portal (apivalley.valmont.com) exists but requires account credentials. AgSense 365 and BaseStation3 are proprietary platforms for registered Valley equipment owners. Contact Valley Irrigation directly for developer partnership and integration inquiries.
